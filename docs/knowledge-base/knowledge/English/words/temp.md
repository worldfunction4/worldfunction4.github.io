# 随写随记的单词

## efficient
efficient  adj.有效率的，有能力的
## structures
structures   n.结构，构造；n.结构，组织

## effective
adj.有效的，产生预期的效果的
This medicine is very effective.（这种药非常有效）

adj.有能力的，能胜任工作的
She is an effective manager. （她是一位能干的管理者）

## record
v.记录
