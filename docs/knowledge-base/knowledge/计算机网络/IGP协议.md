# IGP

<!-- more -->

内部网关协议（Interior Gateway Protocol）：**一个自治系统（AS）内部**用的路由协议。路由器之间交换自己 AS 里的路，不管 AS 外面怎么走。出了 AS，才轮到 [EGP协议](EGP协议.md)（现在实际就是 BGP）。

常见 IGP：

| 协议 | 算法 | 大致定位 |
|------|------|----------|
| [静态路由](静态路由.md) | 人手写 | 小网、缺省路由、备份 |
| [RIP](RIP.md) | 距离矢量 | 跳数，简单，大网不够用 |
| [OSPF](OSPF.md) | 链路状态 | 企业网最常见 |
| [ISIS](ISIS.md) | 链路状态 | 运营商骨干更常见 |

选路时协议之间先比**优先级**（管理距离），同一协议再比度量。华为上常见：直连 0，OSPF 10，ISIS 15，静态 60，RIP 100。
