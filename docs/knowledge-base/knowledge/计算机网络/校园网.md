今天在图书馆偶然发现也有校园网无线覆盖，当我连上后发现和寝室里一样都是10.40.0.0/16，所以我很好奇：这究竟是如何做到的？在我询问了AI后，得到了以下的答案

## 是否使用了三层交换机或者路由器？

答案是：正好相反。

**在不同地点都拿到 10.40.0.0/16 的 IP，恰恰说明学校用了三层设备（路由器/三层交换机）**。
原因很直接：

**如果没用三层设备（纯二层网络）：**

- 10.40.0.0/16 有 65536 个地址，这是一个巨大的广播域
- 寝室和图书馆的所有设备都在同一个广播域里，ARP 广播会泛洪全网
- 这个规模的二层网络早就瘫痪了，根本无法使用

**现实中的校园网架构（三层方案）：**

```Text
寝室楼                      图书馆
  │                          │
  ├─ 接入交换机(VLAN 100)      ├─ 接入交换机(VLAN 200)
  │                          │
  └── 汇聚层(三层交换机) ──── 核心路由器 ──── 汇聚层(三层交换机) ──┘
                    │
               DHCP 服务器
            (统一分配 10.40.0.0/16)
```

更合理的解释是：

- 每个区域有独立的 VLAN，由三层交换机做本地路由
- DHCP 通过 **DHCP Relay** 统一由中心服务器分配 10.40.0.0/16 的地址
- 你做 `tracert` 或者 `ipconfig /all` 看网关，不同地点的网关 IP 大概率是不同的

**验证方法：** 在寝室和图书馆分别跑 `ipconfig`，看看默认网关是否不一样。不一样就确认有三层路由了。

## 寝室里连上的校园网是和寝室一台交换机还是一个寝室楼？

个人觉得后者不太可能，不然早就引发[广播风暴](/knowledge-base/knowledge/专业术语/广播风暴.md)，但是一个寝室一台交换机学校未免太富有了，估计也不太可能。如果折中的话最可能的情况是：**寝室楼共用汇聚交换机（每个楼层一台），而非每个寝室一台独立交换机**。那么如何来验证呢？通过搜集信息我得到有以下的方法：
### 方法 1：ARP 表看广播域规模

```Bash
arp -a
```

数一下返回了多少个 `10.40.x.x` 的条目。如果只有个位数（同寝室 4-6 台设备），偏向寝室小交换机；如果几十上百条，那广播域覆盖的是整层甚至整栋楼。10.40.0.0/16 本身就已经说明广播域很大了（不可能每个寝室用 /16）。这也是只有一台设备时最合适的方法？

### 方法 2：抓包看交换机 MAC

这个方法需要会[抓包](/knowledge-base/knowledge/计算机网络/抓包.md)，装 Wireshark，混杂模式下抓几分钟广播包（ARP、DHCP、MDNS）。每个二层设备通过的帧会带上交换机的 Bridge ID 或 STP BPDU。如果同楼层多个寝室的同学抓到的 **根桥 MAC 相同**，说明在同一台核心交换机下。当然也可以试试**LLDP 碰运气**，部分校园网交换机开了 [LLDP](/knowledge-base/knowledge/专业术语/LLDP.md)， 抓包过滤 `lldp`，如果能有 LLDPDU 包，里面直接写着交换机型号、端口号、管理 IP。

### 方法 3：物理巡查

去楼层弱电井看一眼——校园网标准做法通常是：
- **每层楼一个弱电间**，里面有 1-2 台 48 口接入交换机
- 每个寝室的墙上网口直接走线到该层的弱电间
- 各楼层交换机再通过光纤上行到楼栋汇聚交换机（三层）

如果一个寝室 4 个网口都接在同一台 48 口交换机上，那就不是"寝室独享"。

### 方法 4：tracert 看跳数

```Bash
tracert <同楼层隔壁寝室的IP>
tracert <不同楼层的IP>
```

如果两个目标第一跳都是同一个网关 IP 且跳数相同，说明都在同一台三层交换机下；如果同楼层比跨楼层少一跳，说明楼层之间有独立二层设备。

### 方法 5：MAC 地址表 OUI 查询

`arp -a` 拿到的 MAC 地址，到 [Wireshark OUI Lookup](https://www.wireshark.org/tools/oui-lookup.html) 或 `https://macvendors.com` 查厂商标识。如果所有设备出现在同一台交换机厂商（如 H3C/Huawei/Ruijie）的 MAC 下，就是接入同一台交换机。
