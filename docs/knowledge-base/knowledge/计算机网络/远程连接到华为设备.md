这里以eNSP为例

## 第一步：基本配置（接口 IP + 用户名）

    <Huawei> system-view

    # 配置接口 IP（让 PC 能路由到设备）
    [Huawei] interface GigabitEthernet 0/0/0
    [Huawei-GigabitEthernet0/0/0] ip address 192.168.1.1 255.255.255.0 # 这里配和虚拟网卡关联的ip
    [Huawei-GigabitEthernet0/0/0] undo shutdown
    [Huawei-GigabitEthernet0/0/0] quit
     # 创建本地用户
    [Huawei] aaa
    [Huawei-aaa] local-user admin password cipher Admin@123
    [Huawei-aaa] local-user admin privilege level 15
    [Huawei-aaa] local-user admin service-type ssh
    [Huawei-aaa] quit

## 第二步：开启 SSH 服务 

telnet同理，但是现在基本不怎么用，因为它是明文传输，并不安全。

	# 生成 RSA 密钥（必须做，否则 SSH 服务起不来）
    [Huawei] rsa local-key-pair create
    # 询问密钥长度时直接回车（默认 1024）或输入 2048

    # 开启 STelnet（华为叫 STelnet，即 SSH）
    [Huawei] stelnet server enable

    # 配置 VTY 线路
    [Huawei] user-interface vty 0 4
    [Huawei-ui-vty0-4] authentication-mode aaa
    [Huawei-ui-vty0-4] protocol inbound ssh
    [Huawei-ui-vty0-4] quit

    # 配置 SSH 用户
    [Huawei] ssh user admin
    [Huawei] ssh user admin authentication-type password
    [Huawei] ssh user admin service-type stelnet

Telnet配置和SSH是一样的，只是不需要配置用户，接下来就能进行远程测试了。
