## 一、文件系统导航

### 核心命令

| 命令 | 全称 | 作用 | 常用选项 |
|------|------|------|----------|
| `pwd` | Print Working Directory | 显示当前位置 | — |
| `ls` | list | 列出目录内容 | `-l` 详细信息, `-a` 含隐藏文件, `-h` 人类可读大小 |
| `cd` | change directory | 切换目录 | — |
| `mkdir` | make directory | 创建目录 | `-p` 递归创建中间目录 |
| `cat` | concatenate | 显示文件内容 | `-n` 显示行号 |
| `cp` | copy | 复制文件 | `-r` 递归复制目录 |
| `mv` | move | 移动/重命名 | — |
| `rm` | remove | 删除 | `-r` 递归, `-f` 强制 |
| `touch` | — | 创建空文件/更新文件时间 | — |
| `echo` | — | 输出文本 | — |

### 路径符号

| 符号 | 含义 |
|------|------|
| `~` | 家目录（你的：`/home/layyes`） |
| `/` | 根目录（文件系统顶部） |
| `..` | 上一级目录 |
| `.` | 当前目录 |
| `-` | 上一个工作目录（配合 `cd -`） |

### 文件系统结构

```
/                    ← 根目录（一切从这里开始）
├── home/layyes/     ← 家目录 (~)
├── etc/             ← 系统配置文件
├── usr/             ← 用户程序
├── var/             ← 日志等可变数据
└── tmp/             ← 临时文件
```

### 重定向与管道

| 符号 | 作用 | 示例 |
|------|------|------|
| `>` | 输出写入文件（覆盖） | `echo "hello" > file.txt` |
| `>>` | 输出追加到文件末尾 | `echo "world" >> file.txt` |
| `\|` | 管道：左边输出 → 右边输入 | `cat f.txt \| sort \| uniq -c` |

管道是 Linux 哲学的核心——**每个命令只做一件事，通过管道组合起来**。

## 二、权限系统

### 权限字符串（10 位）

```
-  rwx  r-x  r--
│   │    │    │
│   │    │    └── others (其他人)  3 位
│   │    └─────── group  (所属组)  3 位
│   └──────────── user   (所有者)  3 位
└──────────────── 类型: -文件  d目录  l软链接
```

### 权限含义

| 字母 | 值 | 对文件 | 对目录 |
|------|-----|--------|--------|
| `r` | 4 | 读取文件内容 (`cat`) | 列出目录内容 (`ls`) |
| `w` | 2 | 修改文件内容 | 创建/删除目录内文件 |
| `x` | 1 | 作为程序执行 | 进入目录 (`cd`) |
| `-` | 0 | 无此权限 | 无此权限 |

### chmod 数字模式

**规则：r=4, w=2, x=1，三个数字分别为 User / Group / Others**

```
chmod  U  G  O
       │  │  │
       7  5  5    →  rwx r-x r-x
       │  │  │
       │  │  └── 5 = 4+1   = r-x
       │  └───── 5 = 4+1   = r-x
       └──────── 7 = 4+2+1 = rwx
```

**常用组合：**

| 数字 | 含义 | 适用场景 |
|------|------|----------|
| `755` | rwx r-x r-x | 可执行程序、目录 |
| `644` | rw- r-- r-- | 普通文件 |
| `600` | rw- --- --- | 私密文件 |
| `700` | rwx --- --- | 私密目录/脚本 |
| `777` | rwx rwx rwx | 所有人可读写执行（危险） |
### chmod 符号模式

格式：`chmod [谁][操作][权限]`

| 谁 | 含义 | 操作 | 含义 | 权限 | 含义 |
|----|------|------|------|------|------|
| `u` | user (所有者) | `+` | 叠加（加上） | `r` | 读 |
| `g` | group (组) | `-` | 减去（去掉） | `w` | 写 |
| `o` | others (其他人) | `=` | 精确覆盖 | `x` | 执行 |
| `a` | all (全部) | | | `X` | 智能执行* |

**\*智能执行 `X`：** 目录一定加 x；文件只在已有角色拥有 x 时才加。常用于 `chmod -R a+X .`（给所有目录加执行，不碰数据文件）

**常用示例：**

```bash
chmod u+x script.sh        # 给所有者加执行
chmod g-w file             # 去掉组的写权限
chmod a+r file             # 所有人可读
chmod u=rwx,g=rx,o= file   # 精确设置：所有者读写执行，组读执行，其他人无
chmod g=u file             # 把所有者权限复制给组
chmod u+w,g+w,o+x file     # 逗号分隔多条设置
chmod -R a+X .             # 递归给所有目录加执行，不影响普通文件
```

**`+` / `-` vs `=` 的核心区别：**

- `chmod g+w` — 只给组**加上**写权限，其他位不变（叠加）
- `chmod g=w` — 组的权限**精确覆盖**为只有写，读和执行被清掉
- `chmod 755` — 等同于 `u=rwx,g=rx,o=rx`，一次性精确覆盖所有角色

### 排查权限问题

如果无法访问某个文件，检查**路径上每一级目录**的 `x` 权限——少一个都进不去：

```bash
ls -ld /home /home/layyes /home/layyes/foo   # 逐级检查
```

## 三、常用组合速查

```bash
# 查找大文件
du -sh /* 2>/dev/null | sort -rh | head -5

# 统计各类型出现次数
cat file.txt | sort | uniq -c | sort -rn

# 查找包含关键字的文件
grep -r "pattern" /path/to/dir

# 检查磁盘空间
df -h

# 检查进程
ps aux | grep process-name
