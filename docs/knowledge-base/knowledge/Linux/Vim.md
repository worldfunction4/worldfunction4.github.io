# Vim 键位速查

## 核心概念

Vim 有四种模式，日常主要用前两种：

| 模式 | 进入方式 | 光标外观 | 用途 |
|------|---------|---------|------|
| **普通模式 (Normal)** | `Esc` / `Ctrl+[` | 方块 ▮ | 移动、删除、复制、粘贴 |
| **插入模式 (Insert)** | `i` `a` `o` `I` `A` `O` | 细线 ▏ | 正常打字 |
| 可视模式 (Visual) | `v` `V` `Ctrl+v` | 方块 | 选中文本 |
| 命令模式 (Command) | `:` | — | 保存、退出、搜索替换等 |

> **黄金法则**：时刻记住自己在哪个模式。看不清就按 `Esc` 回到普通模式。

## 删除 / 修改 / 复制

### 操作符 + 动作

Vim 的精髓：**操作符 + 移动范围 = 操作**。

格式：`[数字] + 操作符 + 移动`

| 操作符 | 含义 |
|--------|------|
| `d` | 删除 (delete) |
| `c` | 修改 (change) — 删除并进入插入模式 |
| `y` | 复制 (yank) |
| `>` | 增加缩进 |
| `<` | 减少缩进 |

### 常用组合

| 快捷键 | 作用 |
|--------|------|
| `dw` | 删除一个单词 |
| `d$` 或 `D` | 删除到行尾 |
| `d0` | 删除到行首 |
| `dd` | 删除整行 |
| `3dd` | 删除 3 行 |
| `diw` | 删除当前单词（光标在单词内即可） |
| `daw` | 删除当前单词 + 前后空格 |
| `di(` 或 `dib` | 删除括号内内容 |
| `da(` 或 `dab` | 删除括号及内部内容 |
| `di"` | 删除双引号内内容 |
| `dit` | 删除 HTML/XML 标签内内容 |
| `dat` | 删除标签及内部内容 |
| `ciw` | 修改当前单词 |
| `ci(` | 修改括号内内容 |
| `C` | 修改到行尾 |
| `yy` | 复制整行 |
| `3yy` | 复制 3 行 |
| `yiw` | 复制当前单词 |
| `p` | 粘贴到光标后 |
| `P` | 粘贴到光标前 |

> `i` 在范围里表示 **inside**（内部），`a` 表示 **around**（包含边界）。

## 替换

```
:s/old/new/g         当前行替换所有
:%s/old/new/g        全文替换所有
```

## 寄存器（剪贴板）

Vim 有多个"寄存器"，其中 `"+` 是系统剪贴板。

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 复制到系统剪贴板 | `"+y` | `"` `+` `y` 按顺序 |
| 从系统剪贴板粘贴 | `"+p` | `"` `+` `p` 按顺序 |
| 剪切到系统剪贴板 | `"+d` | `"` `+` `d` 按顺序 |
| 查看所有寄存器 | `:reg` | |

> VS Code Vim 设置中可以开启 `vim.useSystemClipboard: true`，让 `y` / `p` 默认走系统剪贴板。

## 实用技巧

### 数字前缀就是重复次数

```
5j       向下 5 行
3dd      删除 3 行
10yy     复制 10 行
4w       向前跳 4 个单词
```

### `.` 重复上一次修改

```
dd      删除一行
.       再删除一行（重复）
```

### `Ctrl+o` / `Ctrl+i` 跳转历史

| 按键 | 作用 |
|------|------|
| `Ctrl+o` | 跳回上一个位置 |

## VS Code Vim 专属

### 冲突处理

VS Code 有些快捷键和 Vim 冲突，在 settings.json 中可以控制：

```json
{
  "vim.handleKeys": {
    "<C-d>": false,     // Ctrl+d 留给 VS Code（多光标）
    "<C-a>": false,     // Ctrl+a 留给 VS Code（全选）
    "<C-w>": false,     // Ctrl+w 留给 VS Code（关闭标签）
    "<C-p>": false      // Ctrl+p 留给 VS Code（文件搜索）
  }
}
```

设置为 `false` = 交给 VS Code 处理（不交给 Vim）。

### 推荐设置

```json
{
  "vim.useSystemClipboard": true,   // 默认使用系统剪贴板
  "vim.useCtrlKeys": true,          // 启用 Ctrl+r 重做等
  "vim.hlsearch": true,             // 高亮搜索结果
  "vim.leader": "<space>",          // Leader 键设为空格
  "vim.easymotion": true            // 启用 EasyMotion 快速跳转
}
```
