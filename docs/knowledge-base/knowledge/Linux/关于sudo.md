今天在使用apt命令时突然想到：为什么使用sudo就能把apt命令的权限提高呢？于是我带着问题去询问了AI，整理后得到的答案如下：
	`sudo` 是 **Superuser Do**（以超级用户身份执行）的缩写。Linux 系统的设计哲学是“默认最小权限”，普通用户不能修改系统关键文件或安装软件，只有 `root`（超级用户）才能操作。`sudo` 允许提权的原理如下：
**1. 提权凭证与配置文件（`/etc/sudoers`）** 当你在命令前加上 `sudo` 时，系统并不会直接无条件放行，而是先去读取安全配置文件 `/etc/sudoers`。

- 该文件记录了**哪些用户**可以借用 root 权限、可以执行**哪些命令**，以及是否需要输入密码。
    
- 只有你的账号在这个“白名单”里，`sudo` 才会处理你的请求。
    
**2. 身份验证机制** `sudo` 会提示你输入**你自己的用户密码**（而不是 root 用户的密码）。一旦验证成功，系统会在短时间内（默认 15 分钟）记住你的身份令牌，期间再用 `sudo` 就无需重复输入密码。

**3. Linux 内核机制：`setuid` 位与权限切换** 这是最核心的技术原理。在 Linux 文件系统中，`sudo` 这个可执行程序文件（位于 `/usr/bin/sudo`）被设置了一个特殊的权限标志位，叫做 **`setuid` (Set User ID)**。

- **普通程序**：通常情况下，你运行一个程序，这个程序就只具备你当前的权限。
    
- **带 `setuid` 的程序**：无论**谁**去运行这个程序，该程序在运行的那一刻，都会**临时借用该文件所有者的权限**。
    
- `sudo` 可执行文件的所有者正是 `root`。因此，当普通用户触发 `sudo` 时，系统借由 `setuid` 机制将运行进程的有效用户 ID（EUID）临时切换成了 0（即 `root` 的 ID），从而拥有了对系统的最高控制权。
