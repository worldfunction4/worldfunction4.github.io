# 栈展开

在 C++ 中，当异常被抛出时，系统会沿着函数调用链向上寻找匹配的 `try-catch` 块。在这个寻找过程中，**系统会按照与构造相反的顺序，依次自动销毁沿途所有栈上的局部变量**。


## 例子
<!-- more -->

如果在同一个函数里，我们按顺序创建了两个[智能指针](../C和C++/C++11现代特性/智能指针.md) `p1` 和 `p2`：
```cpp
auto p1 = std::make_unique<Person>();
auto p2 = std::make_unique<Person>();
throw std::runtime_error("出错了！");
```
当异常触发**栈展开**时，`p1` 和 `p2` 谁的析构函数会先被调用？


答案是`p2`。
**栈内存严格遵循“后进先出”（LIFO - Last In, First Out）** 的原则 。因为 `p2` 后定义，它在栈上的位置更靠上，所以在发生**栈展开**（或函数正常结束）时，`p2` 会首先被析构，随后才是 `p1`。这种确定性的逆序销毁规则，保证了依赖关系不会乱套。
