**LLDP**（Link Layer Discovery Protocol，链路层发现协议）是一个**二层网络协议**，设备用它向邻居通告自己的身份和能力。

##  工作原理

交换机/路由器周期性向直连端口广播 LLDP 报文（目标 MAC `01:80:c2:00:00:0e`），报文里包含：

| 信息类型  | 示例                       |
| ----- | ------------------------ |
| 设备名称  | `Core-Switch-3F`         |
| 端口号   | `GigabitEthernet 1/0/24` |
| 设备型号  | `Huawei S5735-L48P4X`    |
| 管理 IP | `10.40.0.1`              |
| VLAN  | `VLAN 100`               |
收到这个包的设备就知道："我连的是谁、插在哪个口上"。

## 对排查网络拓扑的价值

如果用 Wireshark 抓到了 LLDP 包，就能直接看到：

- 接到了**哪台交换机**（设备名 + 型号）
- 接在交换机的**哪个端口**上
- 交换机**管理 IP** 是多少

这样不需要物理巡查就能确定我们的网口对应的是哪台设备。

## 实际限制

大多数校园网**关了 LLDP**（安全考虑），所以不一定抓得到。如果关了，回到 `arp -a` + ping 扫描的方法更靠谱
