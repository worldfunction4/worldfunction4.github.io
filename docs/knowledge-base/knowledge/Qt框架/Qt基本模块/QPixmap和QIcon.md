# QPixmap和QIcon区别
| **特性**   | **QPixmap (像素图)**                                              | **QIcon (图标)**                                      |
| -------- | -------------------------------------------------------------- | --------------------------------------------------- |
| **本质**   | 针对屏幕显示进行过优化的**像素图像**（Raster Image）。                            | 一个**高层级的图标管理容器**，可以包含多张图片。                          |
| **状态支持** | 不支持状态管理。一张图就是一张图，无法内置“按下”、“禁用”、“悬停”等不同状态。                      | 支持**多状态**（Normal、Disabled、Active、Selected）和**多尺寸**。 |
| **图像操作** | 支持丰富的**图像处理和变换**（如缩放 `scaled()`、旋转、裁剪、像素级读写、结合 `QPainter` 绘图）。 | 主要是逻辑上的包装，不直接提供复杂的像素级图像处理接口。                        |
| **设备关联** | 强关联底层的显示设备（Screen），针对屏幕渲染做过性能优化。                               | 抽象程度更高，它会根据当前绘制它的控件和状态，自动挑选最合适的 `QPixmap` 显示。       |
简单来说：`QPixmap` 是“具体的像素图片”，而 `QIcon` 是“多状态的图标容器”
