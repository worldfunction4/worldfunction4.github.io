# 摘要与介绍

在编写Qt程序时，用 到了一些库，必须保证库对应模块已经加载到项目中了，这样编译过程才会链接到对应的源代码。

## 基础数据类型

Qt的基本数据类型定义在`#include <QtGlobal>`，有：

- `qint8`：signed char
	- 有符号8位数据
- `qint16`：signed short
	- 16位数据类
- `qint32`：signed short
	- 32位有符号数据类型
- `qint64`：long long int
	- 64位有符号数据类型，win中定义为__int64
等...

#  基础的知识体系

## 1. 元对象系统 (Meta-Object System) 与 MOC

Qt 的很多核心特性（如信号槽、动态属性、RTTI）都依赖元对象系统，而不仅仅是纯 C++ 语言特性。

- **`Q_OBJECT` 宏**：任何想使用信号与槽、属性系统或元对象能力的类，必须继承自 `QObject` 并在类定义开头加上 `Q_OBJECT` 宏。
    
- **MOC (Meta-Object Compiler)**：Qt 的预编译器。它会扫描源文件，为包含 `Q_OBJECT` 的类生成额外的 C++ 源文件（如 `moc_xxx.cpp`），实现元对象代码。
    
- **内省与反射能力**：
    
    - `QMetaObjct` / `metaObject()`：运行时获取类名、信号、槽、属性等元信息。
        
    - `qobject_cast<T*>()`：基于元对象系统的安全动态类型转换（比 `dynamic_cast` 更高效，不依赖 C++ RTTI）。
        

## 2. 信号与槽机制 (Signals & Slots)

信号与槽是 Qt 最著名的松耦合通信机制。

- **连接语法**：
    
    - **旧式语法**（基于字符串）：`connect(sender, SIGNAL(valueChanged(int)), receiver, SLOT(setValue(int)));` —— 编译期不检查类型，运行时才报错。
        
    - **新式语法**（基于函数指针）：`connect(sender, &Sender::valueChanged, receiver, &Receiver::setValue);` —— 编译期严格类型检查，支持 Lambda 表达式。
        
- **连接类型 (`Qt::ConnectionType`)**：
    
    - **`DirectConnection`（直接连接）**：信号触发时，槽函数在**发送者线程**中立即同步执行（类似直接回调）。
        
    - **`QueuedConnection`（队列连接）**：信号触发时，打包成事件投递到**接收者线程**的事件循环中异步执行（跨线程通信核心）。
        
    - **`AutoConnection`（自动连接，默认）**：如果发送者与接收者在同一线程，使用 `DirectConnection`；若在不同线程，自动切换为 `QueuedConnection`。
        
- **自定义类型传输**：如果通过队列连接（或跨线程信号）传输自定义 C++ 类型，必须先调用 `qRegisterMetaType<T>()` 注册该类型。
    

## 3. 对象树与内存管理 (Object Tree)

Qt 提供了一套基于父子关系的半自动内存管理机制，有效减少了手动 `delete` 的负担。

- **父子关系 (`parent`)**：创建 `QObject` 或其子类对象时可以指定 `parent`。当父对象析构时，会自动递归析构并销毁其所有子对象。
    
- **析构顺序**：先析构父对象，再销毁子对象；但在同一父节点下的子对象，析构顺序与创建顺序相反（后创建的先析构）。
    
- **栈对象与对象树的坑**：避免在栈上分配子对象的同时将父对象设为栈对象，若声明顺序不当可能导致**二次析构/重复释放**崩溃。
    

## 4. 事件系统与事件循环 (Event System & Event Loop)

信号与槽是对事件系统的高层封装，而底层依赖事件驱动。

- **事件循环 (`QEventLoop` / `QCoreApplication::exec()`)**：Qt 程序启动后进入主事件循环，持续从 OS 系统队列中拉取事件（鼠标点击、按键、绘图、网络 Socket 等）并分发。
    
- **事件分发过程**：
    
    1. `QCoreApplication::notify()` 接收事件。
        
    2. 经过 **事件过滤器 (`eventFilter`)**：如果安装了事件过滤器，可在此阶段拦截/过滤指定对象的事件。
        
    3. 调用目标对象的 `QObject::event()`：负责识别事件类型（如 `QEvent::MouseButtonPress`）并分发给特定的事件处理函数。
        
    4. 执行具体虚函数：如 `keyPressEvent()`, `mousePressEvent()`, `paintEvent()` 等。
        

## 5. Qt Widgets 基础布局与绘图

- **布局管理器 (Layouts)**：
    
    - `QVBoxLayout`, `QHBoxLayout`, `QGridLayout`, `QFormLayout`。
        
    - 理解 `sizePolicy`（尺寸策略，如 `Fixed`, `Expanding`, `Preferred`）和 `sizeHint`（建议尺寸）。
        
- **自定义绘制 (`QPainter`)**：
    
    - 重写 `paintEvent(QPaintEvent *)` 函数。
        
    - 使用 `QPainter` 配合 `QPen`（画笔/边框）、`QBrush`（画刷/填充）、`QPainterPath`（复杂路径）进行界面绘制。
        
- **图形视图框架 (Graphics View Framework)**：
    
    - 用于处理大量图元（数万个矢量图形）的高性能渲染框架。
        
    - 核心三要素：`QGraphicsScene`（场景/数据）、`QGraphicsView`（视图/显示窗口）、`QGraphicsItem`（图元元素）。
        

## 6. Qt 常用核心容器与工具类

- **容器类**：`QString`, `QList`, `QMap`, `QHash`, `QByteArray`。
    
- **隐式共享 (Implicit Sharing / Copy-on-Write)**：
    
    - Qt 的大部分容器和数据类（如 `QString`, `QByteArray`, `QImage`）都采用了“写时复制”技术。浅拷贝极快，只有在尝试修改数据时才会触发深拷贝，极大提升了传值调用的效率。
        
- **智能指针系**：
    
    - `QPointer<T>`：专为 `QObject` 设计的弱引用指针。当引用的 `QObject` 被 `delete` 时，该指针会自动置为 `nullptr`，有效防止野指针。
        
    - `QSharedPointer<T>`, `QWeakPointer<T>`：类似于标准库的 `std::shared_ptr` / `std::weak_ptr`。
