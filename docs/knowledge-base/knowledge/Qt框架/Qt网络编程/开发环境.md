#  引入网络组件
在编写任何网络代码之前，需要先让Qt项目能够识别网络相关的类。在Qt项目中默认只含基础的`Core`和`gui`模块，如果使用网络功能则需要显示配置网络模块，由于使用的是cmake，所以需要在`CMakeLists.txt`中添加以下内容：
```cmake
find_package(Qt6 REQUIRED COMPONENTS Widgets Network)
```
然后链接网络库：
```cmake
target_link_libraries(${PROJECT_NAME} PRIVATE
    Qt6::Widgets
    Qt6::Network
)
```
- `${PROJECT_NAME}`：项目名称
