#  静态方法
这是下意识就能想到的办法，也就是把这个成员函数变为**静态成员函数**，静态成员函数属于类本身，而不属于某个具体对象，所以它在程序启动时就已经存在，不依赖任何对象实例，故而**没有`this`指针**


#  特殊方法
直接通过空指针调用非静态成员函数。
C++中非静态成员函数代码是全类共用的，使用空指针去调用一个非静态成员函数，只要这个函数内部**没有访问任何非静态成员变量**（也就是没有用`this`指针偏移内存），那么程序就不会崩溃正常执行。

## 风险
当然这属于未定义行为边缘或高风险操作，一旦函数的内部无意中访问了成员变量（隐式使用了 `this`），程序会立刻发生段错误（Segmentation Fault / 崩溃）。

## 示例
```cpp
class MyClass {
public:
    void normalFunc() {
        std::cout << "通过空指针调用，但没访问成员变量，安全" << std::endl;
    }
};

int main() {
    MyClass* p = nullptr;
    p->normalFunc(); // 语法上可以编译通过并运行
    return 0;
}

```
