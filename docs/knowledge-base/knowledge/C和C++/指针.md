##  拓展：指针的“开箱”两大内容 (`*` vs `->`)

在 C++ 中，当我们拿到了一个指针（地址口袋）时，想要去访问它指向的变量，有两种核心语法。它们在底层的目的是完全一样的，只是分工不同：

### 1. 解引用操作符 `*指针` —— “把整节车厢揪出来”
* **本质**：顺着地址找到那扇门，一脚把门踹开，把里面的**整个节点本体**作为一个整体呈现出来。
* **等价关系**：如果 `temp` 装着 B 的地址，那么 `*temp` 就**等于**车厢 B 本体。
* **语法痛点**：如果你想继续拿车厢里的具体物品，必须加括号：`(*temp).data`。因为点号 `.` 的优先级比 `*` 高，不加括号编译器会报错。

### 2. 箭头操作符 `指针->` —— “精准拿取某件物品”
* **本质**：它是 C++ 特意为指针设计的**快捷组合技**（等ated于先解引用，再用点号拿取）。
* **动作**：越过了拿取整节车厢的步骤，直接伸手进车厢，把里面的某个具体口袋（如 `data` 或 `next`）抓出来。
* **爽点**：`temp->data` 既省去了打括号的麻烦，看起来也更直观。

### 等价公式
$$\text{指针}\rightarrow\text{口袋} \quad \equiv \quad (*\text{指针}).\text{口袋}$$

###  避：符号选择看“身份”
- 如果变量是 **本体**（如 `Node A`）  必须用 **`.`（点号）**（如 `A.data`）
- 如果变量是 **指针**（如 `Node* temp`） 必须用 **`->`（箭头）**（如 `temp->data`）
