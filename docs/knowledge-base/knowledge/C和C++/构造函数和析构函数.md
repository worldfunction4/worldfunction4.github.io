# 构造函数和析构函数（C++）

## 为什么需要构造函数？

假设写了一个 `Student` 类：

```cpp
class Student {
    std::string name;
    int age;
};
```

当代码执行 `Student s;` 时，`s` 有了，但 `s.name` 和 `s.age` 里面是什么？

- `age` 是未赋值的，值是乱的（垃圾值）
- `name` 会自己变成空字符串 `""`（因为 `std::string` 有默认构造函数）

**问题**：每次创建对象都得手动赋初值，否则可能用垃圾值做运算，出 bug。

**构造函数就是来解决这个问题的**——它保证"对象一出生，里面的东西就是设置好的"。

---

## 什么是构造函数？

**一句话**：对象创建时**自动调用**的函数，用来给成员变量赋初值。

```cpp
class Student {
    std::string name;
    int age;
public:
    // 构造函数：名字和类名相同，没有返回值
    Student() {
        name = "未知";
        age = 0;
    }
};

// 使用时：
Student s;   // ← 此时自动调用 Student()，name 变成 "未知"，age 变成 0
```

### 构造函数的三个特点

1. 函数名**必须和类名一样**
2. **没有返回值**（连 `void` 都不写）
3. 创建对象时**自动调用**，不需要手动调

---

## 什么是析构函数？

**一句话**：对象销毁时**自动调用**的函数，用来做清理工作（释放内存、关闭文件等）。

```cpp
class Student {
    std::string name;
public:
    // 构造函数
    Student() { name = "未知"; }

    // 析构函数：~ + 类名，没有参数，没有返回值
    ~Student() {
        // 对象销毁时自动执行这里的代码
        std::cout << name << " 被销毁了" << std::endl;
    }
};
```

### 析构函数的三个特点

1. 函数名是 `~` + 类名
2. **没有参数**（所以析构函数不能重载，只能有一个）
3. 没有返回值

### 什么时候会"销毁"？

```cpp
void test() {
    Student s;      // 1. 构造：s 诞生
    // ... 干活 ...
}                   // 2. 析构：s 自动销毁（离开作用域）

Student* p = new Student();  // 1. 构造：堆上创建
delete p;                    // 2. 析构：手动删除时调用
```

---

## 大白话总结

| 概念       | 大白话                         |
| -------- | --------------------------- |
| **构造函数** | 对象**出生时**自动执行的一段代码，把成员变量设置好 |
| **析构函数** | 对象**死的时候**自动执行的一段代码，把打扫干净   |

就像开一家店：

- **构造函数** = 开店前的准备工作（摆好货架、打开收银机）
- **析构函数** = 关店后的打扫工作（关灯、锁门、清点现金）

## 构造函数的种类

### 1. 默认构造函数

**定义**：不传参数就能调用的构造函数。

```cpp
class Student {
    std::string name;
    int age;
public:
    // 默认构造函数：没有参数
    Student() {
        name = "未知";
        age = 0;
    }
};

Student s;      // ✅ 调用默认构造函数
Student s_arr[5]; // ✅ 每个元素都调用默认构造函数
```

**有个小坑**：如果你自己写了**任何**构造函数，编译器就不会自动生成默认构造函数了。

```cpp
class Student {
public:
    Student(std::string name) { }  // 写了带参构造
};

Student s;  // ❌ 编译错误！没有默认构造函数了
```

要解决可以手动加一个：

```cpp
class Student {
public:
    Student() { }                     // 手动补一个默认构造
    Student(std::string name) { }    // 带参构造
};
```

---

### 2. 带参构造函数

**定义**：可以传参数进来，用传入的值初始化成员。

```cpp
class Student {
    std::string name;
    int age;
public:
    // 带参构造函数
    Student(std::string n, int a) {
        name = n;
        age = a;
    }
};

Student s("张三", 20);  // ✅ name = "张三", age = 20
```

**和默认构造可以共存**（函数重载）：

```cpp
class Student {
    std::string name;
    int age;
public:
    Student() {                       // 默认构造
        name = "未知";
        age = 0;
    }
    Student(std::string n, int a) {   // 带参构造
        name = n;
        age = a;
    }
};

Student s1;              // 默认：name="未知", age=0
Student s2("李四", 22);  // 带参：name="李四", age=22
```

---

### 3. 拷贝构造函数

**定义**：用一个**已有的对象**来构造一个新的对象。

```cpp
class Student {
    std::string name;
    int age;
public:
    Student(std::string n, int a) { name = n; age = a; }

    // 拷贝构造函数：参数是 const 引用
    Student(const Student& other) {
        name = other.name;   // 把 other 的 name 拷过来
        age = other.age;     // 把 other 的 age 拷过来
    }
};

Student s1("张三", 20);
Student s2(s1);     // ✅ 调用拷贝构造函数，s2 是 s1 的"复制品"
Student s3 = s1;    // ✅ 这也调用拷贝构造函数（注意：不是赋值）
```

**拷贝构造函数的格式是固定的**：

```cpp
类名(const 类名& 其他对象) {
    // 把其他对象的成员变量一一复制过来
}
```

**为什么参数必须是引用（&）？**

```cpp
// ❌ 错误写法
Student(Student other) { }  // 传值！这样本身又要调用拷贝构造，死循环了

// ✅ 正确写法
Student(const Student& other) { }  // 传引用，不会触发拷贝
```

---

### 三种构造函数的创建时机对比

| 代码 | 调用的构造函数 |
|------|--------------|
| `Student s;` | 默认构造 |
| `Student s("张三", 20);` | 带参构造 |
| `Student s2(s1);` | 拷贝构造 |
| `Student s2 = s1;` | 拷贝构造（不是赋值！） |
| `s2 = s1;`（对象已经存在） | 赋值运算符，不是构造 |
