为了在内存中一次性连续挖出 3 个坑，我们需要借助最基础的字节单位——`char`（每个 `char` 占 1 字节）。

- 如果写 `new char(27)`：代表申请 1 个字节的空间，里面填上数字 27。
    
- 如果写 `new char[27]`：代表在内存里连续开辟 **27 个格子**的整块空间。

提一下为什么要用char*？它不是字符指针类型吗？
这涉及 C++ 语言底层设计中最特殊的一个机制：`char*` 在 C++ 中拥有**双重身份**。

1.比如 `'A'`, `'b'`, `"hello"`，这是我们日常写代码时看到的字符。也就是字符类型

2.C++ 语言标准做出了一个硬性规定：**`sizeof(char)` 在任何系统、任何编译器上，都必须严格等于 1 字节（Byte）**

当我们在写一个**内存池**时，我们不需要关心用户未来要往里面放什么
当然在 C++ 中有一条严格的内存安全规则：**不能随意用一种类型的指针去访问另一种类型的数据**
比如用`float*`类型再去操作`int`是未定义行为
但是，`char*`（以及 `unsigned char*`）拥有全语言唯一的特权：**任何对象占用的内存，都可以被安全地看作一串 `char`（字节）数组进行按字节读取或移动**，这不会破坏语言的安全规则。
