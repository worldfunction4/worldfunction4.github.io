# 四种类型转换符

分别是：**static_cast、dynamic_cast、const_cast、reinterpert_cast** 
它们都是类模板

## static_cast(静态转换)

### 使用
- 在**基本数据类型**之间转换，比如将char转为int，带来的安全性由程序员负责
- 有类型指针与`void*`转换
- 类层次结构中基类和派生类之间指针或引用转换
		上行转换：即派生类->基类，安全
		下行转换：即基类->派生类，没有动态类型检查，不安全

主要执行非多态转换操作，代替C中通常的转换操作，当然**隐式转换**都推荐使用这种方式进行转换。

### 代码
```cpp
#include <iostream>

class Base{};
class Derived:public Base{};

int main()
{
    // 1.使用static_cast进行基本数据结构转换
    float a = 3.14;
    int a_int = static_cast<int>(a);
    std::cout << "float:" <<a <<" -> int:"<< a_int << "\n";
  
    // 2.有类型指针和void*进行转换
    int* i_ptr = &a_int;
    void* v_ptr = static_cast<void*>(i_ptr);
    //需要注意的是：不能直接对v_ptr进行解引用操作，因为此指针大小未知
    //再次进行转换
    using llint = long long;
    llint* ll_ptr = static_cast<llint*>(v_ptr);
    std::cout << "*ll_ptr:" << *ll_ptr << "\n";
    // 3.类层次结构基类和派生类指针或引用转换
    //上行转换
    Derived* D_ptr = nullptr;
    Base* B_ptr = static_cast<Base*>(D_ptr);
    //下行转换
    Base* b_ptr = nullptr;
    Derived* d_ptr = static_cast<Derived*>(b_ptr);
    // 这里举一个反面例子：在有类型指针转换
    int b = 4;
    int* p1 = &b;
    //char* p2 = static_cast<char*>(p1); error:Static_cast from 'int *' to 'char *' is not allowed
    return 0;
}
```

输出结果：

```
float:3.14 -> int:3
*ll_ptr:4294967299
```


## dynamic_cast(动态转换)
### 使用

- 用于将一个父类的指针/引用转化为子类的指针/引用（下行转换），基类**必须**要有虚函数，因为 dynamic_cast 是运行时类型检查，需要运行时类型信息，而这个信息是存储在类的**虚函数表**中。
- 对于下行转换，dynamic_cast 是安全的（当类型不一致时，转换过来的是空指针），而 static_cast 是不安全的。
- 对指针进行 dynamic_cast，失败返回 NULL，成功返回正常 cast 后的对象指针；对引用进行 dynamic_cast，失败抛出一个异常，成功返回正常 cast 后的对象引用。
## 代码
```cpp
#include <cstddef>
#include <cstdlib>
#include <iostream>
#include <memory>
#include <new>
  
class Base{
public:
    // 必须要有虚函数
    virtual void func(){std::cout << "Base::func()\n";}
    //重载new运算符
    void* operator new(std::size_t size)
    {  
        void* p = std::malloc(size);
        if(!p)
        {
            throw std::bad_alloc(); //失败抛出异常
        }
        return p;
    }
    //必须把delete也重载
    void operator delete(void* p)noexcept
    {
        std::free(p);
    }
};
  
class Derived:public Base{
public:
    void func()override{std::cout << "Derived::func()\n";}
};

int main()
{
    Base* bp = new Base;
    Derived* dp = dynamic_cast<Derived*>(bp);
  
    Base base;
    Base& o_base = base;
    Derived &o_derived = dynamic_cast<Derived&>(o_base);  //将基类对象引用转换为派生类对象引用

    return 0;
}
```

## const_cast(常量转换)
### 使用
常量指针（或引用）与非常量（或引用）之间转换

- const_cast是四种类型转换符唯一可以对常量进行操作转换符
- 去除常量性属于**危险**，需要谨慎使用。

### 代码
```cpp
int main()
{
    int a = 100;
    const int* b = &a;; //常量指针
    // *b = 200 error:不能通过常量指针修改值哦？
  
    //常量指针->非常量指针，就可以修改常量指针的指向了
    int* p1 = const_cast<int*>(b);
    *p1 = 200;

  
    //非常量指针->常量指针
    const int* p2 = const_cast<const int*>(p1);


    //常量引用->非常量引用
    const int value = 4;
    const int &o_value = value;//常量引用

    int& c_value1 = const_cast<int&>(o_value);//非常量引用


    //非常量引用->常量引用
    const int& c_value2 = const_cast<const int&>(c_value1);

  
    return 0;
}
```

## reinterpert_cast(不相关类型转换)

### 使用
- 任意指针（或引用）类型都可以转换
- 能够把整形->指针，或指针->整形或数组
它是从底层对数据进行了重新的解释，依赖具体的平台，可移植性比较差，**非必要不使用**，高危。

### 程序
```cpp
#include <cstdint>
#include <iostream>

int main()
{
    int value = 100;
  
    // 1. 用在任意指针类型之间的转换
    double *pd = reinterpret_cast<double *>(&value);
    std::cout << "pd 自身的地址值 = " << pd << std::endl;

    // 2. reinterpret_cast 将指针值转换为整数值
    int *pv = &value;
    std::uintptr_t pvaddr = reinterpret_cast<std::uintptr_t>(pv); // 正确转换
    std::cout << "pvaddr = 0x" << std::hex << pvaddr << std::endl;
    std::cout << "pv     = " << pv << std::endl;
}
```

输出：

```
pd 自身的地址值 = 0x7ffdf8ea9bac
pvaddr = 0x7ffdf8ea9bac
pv     = 0x7ffdf8ea9bac
```
