智能指针和裸指针最大的区别就是在new了之后不需要手动清空内存，智能指针实际上是一个类，里面管理着裸指针，在智能指针使用完毕后调用析构函数时就会把申请的内存顺手清空而不需要手动清空。

头文件：`#include <memory>`
类模板: `unique_ptr<数据类型> 变量`
一个 unique_ptr 类型的智能指针管理一个内存

声明一个智能指针： `unique_ptr<Person> pu;`
