# 迭代器（Iterator）

## 迭代器是什么

迭代器是一种**统一遍历接口**，让开发者用相同的方式遍历不同容器（vector、list、map 等），而不必关心容器的底层结构。

```cpp
// 无论什么容器，遍历写法都一样
std::vector<int> vec = {1, 2, 3};
std::list<int> lst = {1, 2, 3};
std::map<int, std::string> mp = {{1, "a"}, {2, "b"}};

auto it = vec.begin();  // vector 的迭代器
auto it = lst.begin();  // list  的迭代器，用法一样
auto it = mp.begin();   // map   的迭代器，用法一样
```

**本质**：迭代器是对"指针"的抽象，重载了 `++`、`*`、`!=` 等运算符，使其表现得像指针。

---

## 基本用法

```cpp
std::vector<int> vec = {10, 20, 30};

// 遍历
for (auto it = vec.begin(); it != vec.end(); ++it) {
    std::cout << *it << " ";  // 10 20 30
}

// 范围 for 循环（底层就是迭代器）
for (int x : vec) {
    std::cout << x << " ";
}
```

## 迭代器种类（五类）

| 种类 | 功能 | 示例 |
|------|------|------|
| **输入迭代器** | 只读、单向、一次遍历 | `std::istream_iterator` |
| **输出迭代器** | 只写、单向、一次遍历 | `std::ostream_iterator` |
| **前向迭代器** | 可读写、单向、多次遍历 | `std::forward_list` |
| **双向迭代器** | 可读写、双向（支持 `--`） | `std::list`、`std::set` |
| **随机访问迭代器** | 可读写、支持 `+n`、`-n`、`[]` | `std::vector`、`std::deque` |

### 随机访问 vs 双向的区别

```cpp
auto it = vec.begin();

it + 3;     // ✅ vector 的迭代器支持（随机访问）
it[2];      // ✅ vector 支持
it1 < it2;  // ✅ vector 支持比较大小

auto it2 = lst.begin();
it2 + 3;    // ❌ list 的迭代器不支持（双向迭代器）
it2[2];     // ❌ list 不支持
```

## 常用操作

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

auto it = v.begin();   // 指向第一个元素
auto end = v.end();    // 指向最后一个元素的后面（尾后迭代器）

*it;                   // 访问元素
++it;                  // 指向下一个
--it;                  // 指向前一个（双向/随机访问才支持）
it += 2;               // 向前移动两步（仅随机访问）

// 遍历
for (auto it = v.begin(); it != v.end(); ++it)
    *it *= 2;          // 修改元素值

// C++11 范围 for（等效写法）
for (auto& x : v)
    x *= 2;
```

## 迭代器失效（重要）

**迭代器失效**：容器内容发生变化后，已有的迭代器可能变无效，继续使用会导致**未定义行为**。

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};
auto it = v.begin();     // 指向 1

v.push_back(6);          // vector 可能扩容，所有迭代器失效
std::cout << *it;        // ❌ 未定义行为！it 已失效
```

### 各类容器的失效情况

| 容器 | 插入 | 删除 | 扩容（vector） |
|------|------|------|--------------|
| `vector` | 插入点**之后**失效；扩容则**全部**失效 | 删除点**之后**失效 | 全部失效 |
| `deque` | 中间插入：**全部**失效；首尾插入：迭代器全失效但引用不失效（C++11） | 中间删除：**全部**失效；首尾删除：仅被删元素失效 | — |
| `list` | ✅ **不失效** | ✅ **仅被删元素**失效 | — |
| `forward_list` | ✅ **不失效** | ✅ **仅被删元素**失效 | — |
| `map`/`set` | ✅ **不失效** | ✅ **仅被删元素**失效 | — |

## 实用的迭代器辅助函数

```cpp
#include <iterator>

auto it = std::begin(vec);   // C++11，等效 vec.begin()
auto end = std::end(vec);    // C++11，等效 vec.end()
auto it = std::next(it, 2);  // 返回 it+2，不改变 it 本身
auto prev = std::prev(it);   // 返回 it-1
int dist = std::distance(begin, end); // 计算两个迭代器的距离
```

## 反向迭代器

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

for (auto it = v.rbegin(); it != v.rend(); ++it)
    std::cout << *it << " ";  // 5 4 3 2 1
```

---

## 常迭代器

```cpp
std::vector<int> v = {1, 2, 3};

auto it = v.cbegin();       // const_iterator，只读
// *it = 10;                // ❌ 编译错误，不能修改

auto it2 = v.begin();       // 普通迭代器，可读写
*it2 = 10;                  // ✅ 可以修改
```

---

## 一句话总结

> **迭代器 = 容器的统一遍历接口**，让所有容器的遍历写法一致。

| 场景 | 写法 |
|------|------|
| 只读遍历 | `for (auto it = c.cbegin(); it != c.cend(); ++it)` |
| 读写遍历 | `for (auto it = c.begin(); it != c.end(); ++it)` |
| 反向遍历 | `for (auto it = c.rbegin(); it != c.rend(); ++it)` |
| 范围 for | `for (const auto& x : c)` |
