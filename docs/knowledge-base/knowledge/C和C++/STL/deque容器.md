# deque容器

`<deque>` 是标准模板库（STL）的一部分，它提供了双端队列（double-ended queue）的实现

双端队列是一种允许在两端进行插入和删除操作的线性数据结构。

它是一个动态数组，它提供了快速的随机访问能力，同时允许在两端进行高效插入和删除操作，使得 `<deque>` 成为处理需要频繁插入和删除元素的场景的理想选择。

## 使用

头文件：`<deque>`

```cpp
std::deque<int> mydeque; //创建整数类型的双端队列
//进行插入等操作
```
