先看代码：
```cpp
#include <thread>
#include <print>

int m = 0;

void doSomething()
{
    for(int i = 0; i < 10000; i++)m++;
}

int main()
{
    std::thread ts[20];
    for(auto &t : ts)
    {
        t = std::thread(doSomething);
    }
    for(auto &t : ts)
    {
        t.join();
    }
    std::println("{}", m);
  	return 0;
}
```

运行两次后得到了以下的结果：`127313`和`170007`。为什么一样的程序两次结果不同？
答案是**同时进行无次序会导致多个线程进行同时操作一个变量出现问题**，这时候就需要`std::mutex`和`std::atomic`。
