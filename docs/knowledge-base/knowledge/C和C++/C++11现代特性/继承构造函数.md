# 继承构造函数

C++中，如果一个基类有多个构造函数，那么派生类为了继承它们，就需要手动将参数逐个传递给基类：
```cpp
class Base {
public:
    Base(int a) {}
    Base(double b) {}
    Base(std::string c) {}
};

// 传统写法：必须手动重复编写所有构造函数
class Derived : public Base {
public:
    Derived(int a) : Base(a) {}
    Derived(double b) : Base(b) {}
    Derived(std::string c) : Base(c) {}
};
```

在C++11引入`using`，能直接把基类构造函数继承：
```cpp
// 一行代码继承所有构造函数
class Derived : public Base {
public:
    using Base::Base; // 声明继承基类的所有构造函数
};
```
这样，`Derived` 对象就可以直接使用 `int`、`double` 或 `string` 参数来进行构造了。
但是如果Dericed类新增了一个成员变量：
```cpp
class Derived : public Base{
private:
	int extra_;
public:
	using Base::Base;
};

int main()
{
	Derived d(10);
}
```

这个时候创建对象d时`extra_`会被如何处理？答案是采取默认初始化。这会导致`extra_`没有被赋予默认值，而是随机的无效值。所以类内部成员初始化：
```cpp
class Derived : public Base {
    int m_extra = 0; // 
public:
    using Base::Base; // 继承构造函数
};
```

 此时如果进行以下操作：
 ```cpp
 int main()
 {
	 Derived d(100);
	 return 0;
 }
 ```

这个时候由于Derived中有`using Base::Base`，所以会**自动生成**一个等价于
```cpp
Derived(int x): Base(x){}
```
的构造函数。
