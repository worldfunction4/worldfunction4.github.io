# 生产者-消费者模型

可以简单理解为：**一个线程负责生产任务，另一些线程负责拿走任务并执行**。

比如一个下载器：

生产者                    消费者
   ↓                         ↓
不断产生下载任务  →  任务队列  →  不断取任务下载

其中会涉及到：
- `mutex`：防止多个线程同时操作队列
- `condition_variabel`：队列没任务时，让消费者等待
- `cv.wait(lock, 条件)`：等待有任务再继续
