# 函数包装器

也就是`std::functional`，它可以将任何**可调用对象**（Callable Objects）进行类型安全的统一封装与存储

可调用对象在C++中有很多：
- 普通函数
- 函数指针
- lambda表达式
- 函数对象（重载了`operator()`的结构体/类）
- 类成员函数与成员变量

语法如下：
```cpp
#include <functional>

std::functional<返回值类型(参数类型1, 参数类型2, ...)> var_name;
```

## 用法

### 封装普通函数与静态成员函数
```cpp
#include <iostream>
#include <functional>

int add(int a, int b) { return a + b; }

int main() {
    // 签名 matching: int(int, int)
    std::functional<int(int, int)> func = add;
    std::cout << func(3, 4) << std::endl; // 输出 7
}
```

### 封装lambda表达式与仿函数
```cpp
struct Multiply {
    int operator()(int a, int b) const { return a * b; }
};

int main() {
    // 封装 Lambda
    std::functional<int(int, int)> lambdaFunc = [](int a, int b) { return a - b; };
    std::cout << lambdaFunc(10, 4) << std::endl; // 输出 6

    // 封装仿函数
    std::functional<int(int, int)> functorFunc = Multiply();
    std::cout << functorFunc(3, 4) << std::endl;  // 输出 12
}
```

### 封装类成员与成员变量
```cpp
#include <iostream>
#include <functional>

class Calculator {
public:
    int num = 100;
    int multiplyBy(int x) const { return num * x; }
};

int main() {
    Calculator calc;

    // 1. 绑定成员函数：第一个参数传入 Calculator 的引用/指针
    std::functional<int(const Calculator&, int)> memFunc = &Calculator::multiplyBy;
    std::cout << memFunc(calc, 3) << std::endl; // 输出 300

    // 2. 绑定成员变量（当作获取成员值的只读函数）
    std::functional<int(const Calculator&)> memVar = &Calculator::num;
    std::cout << memVar(calc) << std::endl; // 输出 100
}
```

### 和`std::bind`结合使用
利用 `std::bind`，可以提前绑定部分参数或调整参数顺序，然后再存入 `std::functional` 中：
```cpp
#include <iostream>
#include <functional>

void printSum(int a, int b) {
    std::cout << a + b << std::endl;
}

int main() {
    using namespace std::placeholders; // 提供 _1, _2 等占位符

    // 把第一个参数固定为 10，生成一个只需要传递一个参数的新函数
    std::functional<void(int)> addTen = std::bind(printSum, 10, _1);
    addTen(5); // 相当于 printSum(10, 5)，输出 15
}
```
