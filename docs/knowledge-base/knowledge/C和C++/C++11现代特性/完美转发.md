# 完美转发

## 背景

完美转发（Perfect Forwarding）是 C++11 引入的一种编程技巧，它的核心目的只有一个：**在将参数传递给另一个函数时，完全保留参数的原始属性（包括左值/右值属性、`const`/`volatile` 限定符）**，那为什么需要完美转发呢？在c++中，只要右值有了名字，在当前作用域就会变成一个左值，这就导致“属性丢失”，有个例子:
```cpp
#include <iostream>

void process(int& x)  { std::cout << "处理左值\n"; }
void process(int&& x) { std::cout << "处理右值\n"; }

// 中转函数（包装函数）
template <typename T>
void wrapper(T&& arg) {
    // 即使传入的是右值，arg 在这里是一个有名字的变量，因此 arg 本身是左值！
    process(arg); 
}

int main() {
    int a = 10;
    wrapper(a);  // 传入左值，期望调用 process(int&)，实际调用 process(int&)
    wrapper(10); // 传入右值，期望调用 process(int&&)，结果依然调用了 process(int&)
}
```

`wrapper(10)` 传入了右值 `10`，但在 `wrapper` 函数内部，`arg` 变成了一个有名字的变量，系统把它当作**左值**对待。最终 `process(arg)` 匹配了左值重载版本，右值属性丢失了。
那我们想要保留要怎么办呢？使用`std::move`？不，这样左值也会变成右值了

## 完美转发解决方案：`std::forward`

完美转发依靠两个机制配合实现：

1. **万能引用（Universal Reference / Forwarding Reference）**：`T&&` 在模板参数推导时，既能接收左值也能接收右值
    
2. **引用折叠规则（Reference Collapsing）**：
    
    - `T& &` $\rightarrow$ `T&`
        
    - `T& &&` $\rightarrow$ `T&`
        
    - `T&& &` $\rightarrow$ `T&`
        
    - `T&& &&` $\rightarrow$ `T&&`
        
3. **`std::forward<T>(arg)`**：根据模板类型 `T`，强转还原参数原本的左值或右值属性

这样上面的例子就可以变成：
```cpp
#include <iostream>
#include <utility> // 包含 std::forward

void process(int& x)  { std::cout << "处理左值\n"; }
void process(int&& x) { std::cout << "处理右值\n"; }

template <typename T>
void wrapper(T&& arg) { // T&& 为万能引用
    // 使用 std::forward 完美转发参数
    process(std::forward<T>(arg)); 
}

int main() {
    int a = 10;
    wrapper(a);  // 输出：处理左值 （T 被推导为 int&，std::forward 返回 int&）
    wrapper(10); // 输出：处理右值 （T 被推导为 int， std::forward 返回 int&&）
}
```
