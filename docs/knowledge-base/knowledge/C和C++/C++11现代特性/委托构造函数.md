# 委托构造函数

顾名思义，就是在一个构造函数中调用其他的构造函数：
```cpp
class Test {
public:
	Test()
	{
		std::cout << "调用Test()\n";
	}
	Test(int) :Test()
	{
		std::cout << "调用Test(int)\n";
	}
};
```
这就是为了避免代码重复。
```cpp
class Test {
public:
	Test(int a, int b):a_(a),b_(b)
	{
		std::cout << "调用Test()\n";
	}
	Test(int x) :Test(x, 0)
	{
		std::cout << "调用Test(int)\n";
	}
private:
	int a_;
	int b_;
};
```
如果：
```cpp
Test(int x):Text(x, 0), b_(0){}
```
这是错误的，因为编译器无法处理“既要把所有初始化的控制权交给另一个构造函数，又要在当前列表中单独初始化某个成员”这种矛盾的操作。
