# lambda表达式

本质上是一个**可以调用的匿名函数对象**。
语法：
```cpp
[捕获列表](参数列表) mutable -> 返回类型 { 函数体 }
```
- `[]`：不捕获任何外部变量
- `[x, &y]`：按**值**捕获 `x`，按**引用**捕获 `y`
- `[=]`：按**值**隐式捕获所有外部变量
- `[&]`：按**引用**隐式捕获所有外部变量
- `[=, &x]`：默认按**值**捕获，但 `x` 特殊按**引用**捕获
- `[&, x]`：默认按**引用**捕获，但 `x` 特殊按**值**捕获

需要注意的是：按值捕获的变量默认是`const(只读)`的，即使变量本身没有`const`。

所以我们既想**修改获取的值却又不想改变外部原本的值**就需要
`mutable`。

```cpp
int a = 1;
auto f = [a]()mutable{
	a = 10; //不会报错
};
f();
//f内的a和外部的a是两个变量，相当于原本和副本
```
