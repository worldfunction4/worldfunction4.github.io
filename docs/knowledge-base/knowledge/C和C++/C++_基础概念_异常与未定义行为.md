# C++ 基础概念：异常抛出 & 未定义行为

## 1. "抛出"（throw）—— 异常机制

### 通俗理解

"抛出"就是程序运行时遇到了**意料之外的情况**，它不自己偷偷扛着，而是**主动报告**："出问题了，你来处理！"

就像餐厅里客人点了一道卖完的菜，服务员不是假装上菜，而是**抛出问题**让经理/客人决定怎么办。

### 代码示例

```cpp
#include <vector>
#include <iostream>
#include <stdexcept>

int main() {
    std::vector<int> v = {1, 2, 3};

    try {
        // v.at(5) 会检查越界，越界就"抛出"一个异常
        std::cout << v.at(5) << std::endl;
    }
    catch (const std::out_of_range& e) {
        // 这里"捕获"异常，决定怎么处理
        std::cout << "越界了！" << e.what() << std::endl;
    }

    std::cout << "程序继续运行..." << std::endl;
}
```

**输出**：
```
越界了！vector::_M_range_check: __n (which is 5) >= this->size() (which is 3)
程序继续运行...
```

### 关键点

| 术语 | 含义 |
|------|------|
| **throw** | 主动抛出异常，相当于喊"出事了！" |
| **try** | 尝试执行可能出错的代码 |
| **catch** | 捕获异常，决定如何处理 |

### v.at() vs v[] 的区别

```cpp
v.at(100);  // 越界 → 抛出 std::out_of_range 异常（安全，可捕获）
v[100];     // 越界 → 不检查，直接访问非法内存（危险！）
```

`at()` 相当于带安检的入口，`[]` 相当于没安检、直接冲。

## 2. "未定义行为"（Undefined Behavior, UB）

### 通俗理解

**未定义行为 = 任何事情都可能发生。**

C++ 标准说："这种情况我不规定应该怎样，编译器想怎样就怎样，后果自负。"

可能的后果包括：
- 运气好：看起来正常运行
- 运气差：程序崩溃
- 最可怕：静默地产生错误结果，你根本不知道出错了
- 甚至：格式化你的硬盘（极端情况，现实中编译器一般不会）

### 常见未定义行为

```cpp
// 1. 数组/vector 越界访问
int arr[3] = {1, 2, 3};
arr[100] = 42;  // UB！访问了不属于你的内存

// 2. 空指针解引用
int* p = nullptr;
*p = 10;        // UB！对空指针写入

// 3. 使用已释放的内存（野指针）
int* p = new int(5);
delete p;
*p = 10;        // UB！p 已经是野指针

// 4. 迭代器失效后使用
std::vector<int> v = {1, 2, 3};
auto it = v.begin();
v.push_back(4);  // 触发扩容，it 失效
*it = 5;         // UB！迭代器已失效

// 5. 除零
int x = 5 / 0;  // UB（对整数而言）

// 6. 有符号整数溢出
int x = 2147483647;  // INT_MAX
x = x + 1;           // UB！
```

### 为什么 UB 可怕？

```cpp
// 你的代码在本地跑得好好的
// 换了个编译器 / 换了个平台 / 开了优化 → 行为完全不同！

int x;
std::cout << x;  // UB：未初始化变量
// GCC Debug:   可能输出 0
// GCC Release: 可能输出随机值
// Clang:       可能直接优化掉这行
```

### 异常 vs 未定义行为

| | 抛出异常 | 未定义行为 |
|------|----------|------------|
| **是否规范** | 标准规定的行为 | 标准不管的行为 |
| **可预测** | ✅ 可捕获处理 | ❌ 完全不可预测 |
| **程序状态** | 可安全恢复 | 可能已损坏 |
| **例子** | `v.at(100)` | `v[100]` |
| **推荐** | ✅ 用 `at()` 安全 | ❌ 别碰 UB |

## 3. 类比总结

| 概念 | 类比 |
|------|------|
| **抛出异常** | 坐高铁过安检，带了违禁品 → 安检拦住你，告诉你问题在哪 |
| **未定义行为** | 翻栅栏进轨道 → 没人拦你，但可能被撞、被电、或者侥幸没事。后果自负。 |

---

> 一句话：**用 `at()` 是让程序在犯错时优雅摔倒，用 `[]` 越界是让程序蒙着眼狂奔。摔倒了你知道疼在哪，蒙着眼你死都不知道怎么死的。**
