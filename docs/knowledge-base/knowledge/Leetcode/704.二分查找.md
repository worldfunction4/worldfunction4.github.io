## 什么是二分查找？

在**有序数组**中快速查找特定元素的算法。它的核心思想是：每次通过比较中间元素，将查找范围缩小一半，直到找到目标或确定不存在。
当然前提条件是：1.数组必须是**已排序**的（一般是升序）。2.支持随机访问（如数组，不能是链表）。
所以以后看到满足这两个条件的都可以考虑一下二分查找。

## 力扣

问题如下：

给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`  ，写一个函数搜索 `nums` 中的 `target`，如果 `target` 存在返回下标，否则返回 `-1`。

你必须编写一个具有 `O(log n)` 时间复杂度的算法。

  
**示例 1:**

>**输入:** `nums` = [-1,0,3,5,9,12], `target` = 9
>**输出:** 4
>**解释:** 9 出现在 `nums` 中并且下标为 4

**示例 2:**

>**输入:** `nums` = [-1,0,3,5,9,12], `target` = 2
>**输出:** -1
>**解释:** 2 不存在 `nums` 中因此返回 -1

**提示：**

1. 你可以假设 `nums` 中的所有元素是不重复的。
2. `n` 将在 `[1, 10000]`之间。
3. `nums` 的每个元素都将在 `[-9999, 9999]`之间。

```
## 在力扣 704 题中

参数是 vector<int>& nums ，这是一个 C++ 标准库容器，不是 C 风格数组。

- sizeof(nums) 返回的是 vector 对象本身的大小（通常是 24 字节，取决于实现），而不是数组中元素的总字节数。
    
- sizeof(nums[0]) 返回的是 int 的大小（通常是 4 字节）。
    
- 两者相除得到的是一个固定的小整数（比如 6），与数组实际长度完全无关。
    
```

所以正确做法：使用 nums.size() 获取元素个数。

左闭右开原则的话代码应该如下：
```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        // 需要二分查找
        // 先写一个下标i
        // 左和右
        int len = nums.size();
        int left = 0;
        int right = len; // 这里也要遵循左闭右开
  
        while(left < right){ // 选择左闭右开
            int mid = left + (right-left) /2; // 这里是为了防止left和right太大溢出
            if(nums[mid] > target){
            right = mid;
            }else if(nums[mid] < target){
                left = mid+1; // 这里要加1，因为如果left=0,right=1时，left=mid会让left                                  一直为0
            }else{
                return mid;
            }
        }
        return -1;
    }
};
```

左闭右闭：
```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        // 左闭右闭原则
        int left = 0;
        int right = nums.size() - 1;
        while(left<=right){
            int mid = left + (right - left)/2;
            if(nums[mid] > target){
                right = mid -1;
            }else if(nums[mid] < target){
                left = mid + 1;
            }else{
                return mid;
            }
        }
        return -1;
    }
};
```

```python
class Solution:
```
