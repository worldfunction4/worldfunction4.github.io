题目：
给定一个含有 `n` 个正整数的数组和一个正整数 `target` **。**

找出该数组中满足其总和大于等于 `target` 的长度最小的 **子数组** `[numsl, numsl+1, ..., numsr-1, numsr]` ，并返回其长度**。**如果不存在符合条件的子数组，返回 `0` 。

**示例 1：**

**输入：**target = 7, nums = [2,3,1,2,4,3]
**输出：**2
**解释：**子数组 `[4,3]` 是该条件下的长度最小的子数组。

**示例 2：**

**输入：**target = 4, nums = [1,4,4]
**输出：**1

**示例 3：**

**输入：**target = 11, nums = [1,1,1,1,1,1,1,1]
**输出：**0

**提示：**

- `1 <= target <= 109`
- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 104`

刚开始理解错了题目意思，以为是寻找满足等于target的所有子数组个数，结果不是
然后尝试以最大数为锚点向周边扩展的想法，不过这个数组并不是有序的，所以这种方法如果最大数离第二大的数很远就不攻自破了，所以需要滑动窗口的解法

## 滑动窗口

**滑动窗口**是一种处理「连续子数组/子串」问题的技巧，想象你有一个可以自动调整大小的**窗口**，在数组上从左向右滑动，动态地包含或排除元素。
那么这道题的解法就是：
```cpp
int left = 0, sum = 0;
int minLen = INT_MAX;
for (int right = 0; right < nums.size(); right++) {
    sum += nums[right];          // 右指针扩展窗口
    while (sum >= target) {      // 一旦满足条件，尝试收缩左边界
        minLen = min(minLen, right - left + 1); // 更新最短长度
        sum -= nums[left];
        left++;                  // 左指针右移，窗口缩小
    }
}
return minLen == INT_MAX ? 0 : minLen;
```
### 为什么叫“滑动”？

- `right` 每次循环向右走一步 → **窗口右侧在滑动**。
    
- `left` 只在满足条件时才向右走 → **窗口左侧也可能向右滑动**。
    
- 窗口整体就像一个可以伸缩的框，从数组左边「滑」到右边。
    

### 滑动窗口的两个关键特点

1. **窗口内的元素是原数组的一段连续区间**。
    
2. **左右指针从不回退** → 每个元素最多进出窗口一次，所以总时间复杂度 **O(n)**。
    

### 什么时候用滑动窗口？

- 处理 **连续子数组/子串** 问题（不能跳着选元素）。
    
- 通常配合 **数组元素全为正数**（这样窗口收缩时和严格减小，才能保证正确性；如果存在负数则需要其他方法如前缀和+哈希）。
    
- 典型题：209（最小和≥target），904（水果成篮），76（最小覆盖子串）。
