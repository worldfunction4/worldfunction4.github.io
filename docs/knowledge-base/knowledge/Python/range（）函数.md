range（）函数是一个 Python 内置的函数，用于生成**整数序列**，常用for来进行迭代，它是**迭代器对象**，不会一次性生成整个列表，用来节省内存。
```Python
range(stop)
range(start,stop,step)
```
- `stop`参数是序列终点（不包括该数字），必须进行指定数字，生成到stop-1即**左闭右开**（高中数学语哦）
- `start`参数是序列起点（包括该数字），默认值为0，可以为负数
- `stop`参数代表步长，默认为1，也可以为负数实现倒序
根据以上来举个例子：range(10)，代表一个[0,1,2,3,...7,8,9]的列表。range(10)和range(0, 10)是等价的，其中`0`代表参数`start`，`10`代表参数`stop`。range(0,10,2),代表一个[0,2,4,6,8]的列表
