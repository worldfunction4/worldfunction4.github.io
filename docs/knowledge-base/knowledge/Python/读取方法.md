# 用于 difflib.unified_diff 函数 的读取方法
## read_text()和readlines()

使用 readlines() 方法读取文件内容的好处主要体现在以下几点： 
逐行读取：readlines() 方法会读取文件的每一行，并将这些行存储在一个列表中。这样可以方便地逐行处理文件内容，而不需要手动分割字符串。 
内存效率：对于非常大的文件，readlines() 方法可能会导致内存使用较高，因为它一次性将整个文件加载到内存中。不过，对于大多数配置文件或中小文件来说，这种内存使用是可以接受的。 
保留换行符：readlines() 方法读取的每一行都保留了原始的换行符（\n）。如果需要处理文件内容时保留这些换行符，readlines() 方法会更合适。 
使用 read_text().splitlines() 也有其优点，特别是在处理文件内容时： 
简化代码：read_text() 方法结合 splitlines() 可以在一行中完成文件读取和分割的操作，使代码更加简洁。 
不保留换行符：splitlines() 方法会去除每一行末尾的换行符，这对于某些需要处理纯文本内容的场景可能更加方便。 
统一编码处理：通过 read_text(encoding='utf-8') 可以明确指定文件的编码格式，确保读取的文本内容是正确的。 
选择使用 readlines() 还是 read_text().splitlines() 取决于具体的需求和场景。如果需要保留换行符，readlines() 可能更合适；如果不需要保留换行符，read_text().splitlines() 则更加简洁。
