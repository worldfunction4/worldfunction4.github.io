简单来说，就是把[多线程](/knowledge-base/knowledge/Python/多进程VS多线程.md#多线程%20Multithreading) 中所消耗的[上下文切换](/knowledge-base/knowledge/专业术语/上下文切换.md) 时间给减去了，增强效率。
传统的线程切换由操作系统内核主导，开销极大。而协程则通过将调度权收归至应用层（用户态），实现了极低成本的高并发。

* **事件循环 (Event Loop)**：协程的调度核心。系统在单线程内运行一个主循环，统一管理所有异步任务的生命周期。 
* **非阻塞式交出控制权 (`await`)**：当任务遇到网络等待（如等待远程主机回显或本地 AI 模型接口返回数据）时，使用 `await` 主动挂起当前上下文，将执行权交还给事件循环，进而无缝调度下一个就绪任务。
* **阻塞规避原则**：在异步函数上下文中，严禁混入任何同步阻塞操作（如密集的 CPU 计算或使用非异步库发起的请求）。任何单点阻塞均会导致整个事件循环停滞，引发全局并发瘫痪。
