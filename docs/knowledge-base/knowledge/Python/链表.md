# 🧠 C++ 与 Python 链表底层内存心法

## 1. 🧱 链表节点结构 (Node)
链表就像一列火车，每个节点都是一节车厢。它的特点是内部数据类型**不统一**：既要装载货物（数据），又要装载下一站的地图（指针）。

### 🛠️ C++ 实现 (结构体)
```cpp
struct Node {
    string data;    // 📦 存放数据
    Node* next;     // 🔗 存放下一个节点的内存地址 (指针)

    // 🏗️ 构造函数 (施工队)：车厢诞生时自动调用
    Node(string d) {
        data = d;
        next = nullptr; // 🌟 初始安全指向空
        cout << data << " 车厢诞生！" << endl;
    }

    // 🗑️ 析构函数 (拆迁队)：车厢报废前一瞬间自动调用
    ~Node() {
        // 如果内部有 new 出来的堆内存，需要在这里 delete
        cout << data << " 车厢被销毁！" << endl;
    }
};
```
## 2. 🔗 核心操作：从无到有连铁链

假设有三节独立的车厢：`Node A("苹果"); Node B("香蕉"); Node C("橙子");`。 目标：连成 `A -> B -> C`。

```cpp
A.next = &B;  // 🍏 A 的挂钩死死勾住 B 的地址 (&B)
B.next = &C;  // 🍌 B 的挂钩死死勾住 C 的地址 (&C)
```

[!NOTE] 💡 顺序法则 从无到有创建链表时，连线顺序比较自由。但如果是在**已有链表中删除节点**，必须先用临时安全绳（指针）拉住下一站，绝对不能让后面的车厢失联！

## 3. ⚔️ C++ vs Python 内存生命周期对决

|**核心维度**|**⚡ C++ (全手动精密控制)**|**🐍 Python (全自动智能回收)**|
|---|---|---|
|**内存位置**|局部变量在**栈 (Stack)**；`new` 出来的在**堆 (Heap)**。|一切皆对象，全在**堆 (Heap)**。|
|**销毁机制**|出了作用域，栈变量自动弹出；堆内存必须手动 `delete`。|依靠**引用计数**，计数归零时垃圾回收器自动抹去。|
|**空值表示**|`nullptr` (空指针，本质是地址 0)。|`None` (一个特殊的空对象)。|
|**安全隐外患**|释放后不设为 `nullptr` 会变成**野指针** ☠️。|只要没有变量指向它，就会被完美回收。|

### 🌍 变量作用域铁律 (通用)

1. **全局变量 (Global)**：如果 `temp` 设为空（`nullptr` / `None`），它们本身会一直存在于内存中，值为空，直到整个程序结束或被再次赋值覆盖。
    
2. **局部变量 (Local)**：一旦函数或大括号 `{}` 执行完毕，变量本身瞬间从内存中被自动回收。
### 注意

- **`delete tv;`** 是为了还清欠操作系统的债（释放堆内存）。
    
- 析构函数里不需要写 **`tv = nullptr;`**，因为装债凭证的口袋（`tv` 变量本身）马上就要和对象一起被系统格式化了。
    
- 在 C++ 中 `delete` 完指针后，一定要记得 **`temp = nullptr;`** 斩草除根！
