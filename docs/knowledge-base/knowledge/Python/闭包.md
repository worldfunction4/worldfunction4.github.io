# 闭包（Closure）

## 从一个问题开始

假设你要写一个函数，每次调用就+1，记录调了多少次：

```python
count = 0
def add():
    global count
    count += 1
    return count

print(add())  # 1
print(add())  # 2
print(add())  # 3
```

这能实现，但有个问题——`count` 是全局变量，谁都能改它。万一别的地方不小心改了 `count`，就乱了。

**有没有办法既记住"当前计数"，又不暴露这个变量？**

---

## 闭包的解法

```python
def counter():
    count = 0           # 这个变量"包"在函数里面
    def add():
        nonlocal count
        count += 1
        return count
    return add          # 返回内部函数，而不是调用它

my_counter = counter()  # my_counter 现在是一个函数

print(my_counter())     # 1
print(my_counter())     # 2
print(my_counter())     # 3
# count 在外部访问不到！
```

**这就是闭包**：一个内部函数 + 它"记住"的外部变量。

---

## 核心：闭包 = 函数 + 它记得的变量

```python
def outer(x):
    def inner(y):
        return x + y
    return inner

add5 = outer(5)    # add5 是一个闭包，它"记住"了 x=5
add10 = outer(10)  # add10 是另一个闭包，它"记住"了 x=10

print(add5(3))    # 8    (5 + 3)
print(add10(3))   # 13   (10 + 3)
```

**`outer(5)` 执行完后，`x=5` 按理说应该被销毁了——但 `inner` 还在引用它，所以 Python 把 `x` 保留了下来。`inner` + 它记住的 `x` 合起来就叫"闭包"。**

---

## 闭包的作用

| 作用 | 说明 |
|------|------|
| **数据隐藏** | 变量暴露在外部，但外部不能直接改 |
| **函数工厂** | 根据参数生成不同行为的函数（如上方的 `add5` 和 `add10`） |
| **函数式编程** | Python 装饰器的底层原理就是闭包 |

---

## 跟全局变量的对比

```python
# 全局变量方式
count = 0           # 谁都能改 count
def add():
    global count
    count += 1
    return count

# 闭包方式
def make_counter():
    count = 0       # count 被"包"在里面，外部看不到
    def add():
        nonlocal count
        count += 1
        return count
    return add
```

**闭包的最大价值**：数据 + 操作数据的函数绑定在一起，外部不能乱动内部数据。

---

## 与 C++ lambda 的对应关系

闭包 ≈ C++ 的 lambda 表达式捕获外部变量：

```cpp
auto make_counter() {
    int count = 0;
    return [count]() mutable {
        return ++count;
    };
}

auto c = make_counter();
cout << c();  // 1
cout << c();  // 2
cout << c();  // 3
```

---

## 一句话总结

> **闭包 = 内部函数 + 它"记住"的外部变量**

```python
def outer(x):
    def inner(y):
        return x + y   # inner 用到了 outer 的 x
    return inner       # 返回 inner，它带着 x 一起走
```
