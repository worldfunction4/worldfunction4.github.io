# 生成器

<!-- more -->

生成器是一种**惰性**的迭代器：需要下一个值时才算，而不是一次性把整个序列造出来。函数体里出现 [yield](yield.md)，调用它不会跑完函数，而是返回一个生成器对象。

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

g = countdown(3)   # 还没开始算
print(next(g))     # 3
print(next(g))     # 2
print(list(g))     # [1]，把剩下的耗尽
```

和列表的差别：`[i for i in range(10**7)]` 先占一大块内存；`(i for i in range(10**7))` 是生成器表达式，几乎不占。所以 `difflib.unified_diff` 这类 API 才返回生成器，一行行吐 diff，见 [difflib库](difflib库.md)。

`yield` 把函数的位置记住，下次 `next()` 从暂停处继续。函数正常结束（或 `return`）再 `next()` 会抛 `StopIteration`，`for` 循环会帮你接住。
