所有的列表推导式，其实就是一个固定公式。只要把下面这个中文公式套进去，就全明白了：

**`[ 【核心动作 / 最终要收集的东西】 for 【单个元素】 in 【一堆元素】 ]`**


我们拿一个数字列表翻倍的例子来套公式： 假设有一个列表 `old_list = [1, 2, 3]`，我们想把每个数字乘以 10。

- **【单个元素】 in 【一堆元素】** 对应代码：`for num in old_list` （把 1, 2, 3 挨个取出来，取名叫做 num）
    
- **【核心动作】** 对应代码：`num * 10` （把取出来的那个数字乘 10）
    

拼在一起就是： `new_list = [ num * 10 for num in old_list ]` _(结果：[10, 20, 30])_
