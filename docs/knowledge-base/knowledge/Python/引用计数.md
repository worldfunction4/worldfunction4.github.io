# 引用计数

CPython 用**引用计数**判断对象能不能销毁：有一份引用就 +1，引用没了就 -1，减到 0 立刻回收。

```python
a = []       # 这个 list 计数 1
b = a        # 计数 2
del b        # 计数 1
del a        # 计数 0，对象被销毁
```

两个问题：

1. **多线程同时改计数**会出事：计多数会泄漏，计少数会把还在用的对象拆掉。CPython 用 [GIL(全局解释器锁)](<../专业术语/GIL(全局解释器锁).md>) 保证同一时刻只有一个线程在改这些结构。
2. **循环引用**计数值永远到不了 0（`a = []; a.append(a)`）。所以还有分代 GC 专门扫环。
